# Velore — Project Guidelines

## Про проєкт

Velore — це e-commerce вебсайт для продажу брендового одягу, взуття та парфумів.
Стек: Django (backend), Node.js (де застосовно для frontend-тулінгу/SSR).

## Вимоги до коду

- Використовувати **хороші, ідіоматичні методи програмування з Django** (best practices),
  код має бути написаний на **експертному/senior рівні**.
- Для Django:
  - Правильна структура застосунків (apps), "товстi" моделі / "тонкi" view, де це доречно.
  - Коректна робота з ORM: уникати N+1 запитів, використовувати `select_related` /
    `prefetch_related`, `only()`/`defer()` де потрібно.
  - Використовувати вбудовані механізми Django (auth, permissions, forms/serializers,
    migrations) замість написання власних "велосипедів".
  - Settings розділені по середовищах (dev/staging/prod).
  - Signals використовувати обережно, лише коли це дійсно виправдано.
- Для Node.js: чиста модульна структура, правильна обробка async/await та помилок
  на межах системи (API, зовнішні сервіси).
- Уникати хаків, антипатернів та "швидких, але брудних" рішень, навіть якщо вони
  працюють.

## SEO-вимоги

Сайт має бути **SEO-friendly** — добре індексуватися та ранжуватися в Google та
інших пошукових ботах. При розробці враховувати:

- Семантична HTML-розмітка, правильна ієрархія заголовків (один `<h1>` на сторінку).
- Унікальні, описові `<title>` та `meta description` для кожної сторінки/товару/категорії.
- Open Graph та Twitter Card мета-теги.
- Чисті, читабельні URL (напр. `/category/product-slug`).
- Server-side rendering або pre-rendering для сторінок товарів/категорій — уникати
  client-only рендерингу, який не бачать пошукові боти.
- Структуровані дані (JSON-LD): `Product`, `Offer`, `BreadcrumbList`, `Organization`.
- Продуктивність і Core Web Vitals: оптимізація зображень, lazy loading, мінімум
  render-blocking ресурсів (особливо важливо через велику кількість фото товарів).
- Адаптивність під мобільні пристрої (mobile-friendly).
- `sitemap.xml` (включно з динамічним sitemap для товарів) та `robots.txt`.
- Канонічні URL (`rel=canonical`) — особливо для сторінок з фільтрами, сортуванням
  та пагінацією, щоб уникати дублікованого контенту.
- `alt`-атрибути для всіх зображень товарів.
- Внутрішня перелінковка (пов'язані товари, навігація по категоріях).
